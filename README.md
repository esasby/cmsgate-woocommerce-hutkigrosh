# Модуль оплаты ХуткiГрош (ЕРИП) для WooCommerce

Модуль обеспечивает взаимодействие интернет-магазина на базе **WordPress + WooCommerce** с платёжным сервисом [ХуткiГрош](https://hutkigrosh.by): выставление счетов в ЕРИП (АИС «Расчет»), оплата картой (WebPay), QR-код, автоматическое обновление статусов заказов после оплаты.

> **Важно.** Плагин удалён из каталога плагинов WordPress.org (сентябрь 2025), поэтому установка возможна **только вручную из zip-архива** (инструкция ниже). Поиск по слову «Hutkigrosh» в админке WordPress ничего не найдёт — это ожидаемо, пользуйтесь ссылками из раздела «Скачать».

## Поддерживаемые версии

Поддерживаются **одновременно две версии модуля**:

| | **Hutkigrosh API v3** (рекомендуется) | **WooCommerce Hutkigrosh Gateway** |
|---|---|---|
| Плагин | Hutkigrosh API v3 Gateway for WooCommerce | WooCommerce Hutkigrosh Gateway |
| Текущая версия | 4.0.5 | 4.0.3 |
| API | актуальное поколение (REST API v3) | предыдущее поколение API |
| Подключение | API-токен + выбор услуги из списка | логин/пароль + ERIP ID вручную |
| Тестовая система | api-test-sandbox.hgrosh.by | trial.hgrosh.by |
| Кому подходит | новым магазинам; действующим — при переходе на API v3 | действующим магазинам — работает как раньше |

> **Важно.** Сервис ХуткiГрош пока работает со всеми поколениями API параллельно!

Следите за анонсами ХуткiГрош о сроках отключения старого API и планируйте переход на API v3 заблаговременно (см. раздел «[Переход на API v3](https://github.com/esasby/cmsgate-woocommerce-hutkigrosh/blob/master/README.md#%D0%BE%D0%B4%D0%BD%D0%BE%D0%B2%D1%80%D0%B5%D0%BC%D0%B5%D0%BD%D0%BD%D0%B0%D1%8F-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D0%B8-%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4-%D0%BD%D0%B0-api-v3)»).

## Требования

- WordPress 6.0 и выше (проверено до 6.9), WooCommerce 9.0 и выше (проверено до 10.4.3)
- PHP 7.4 и выше, расширение cURL

## Установка (одинакова для обеих версий)

1. Создайте резервную копию магазина и базы данных.
1. Скачайте zip-архив нужной версии (раздел «Скачать»).
1. В админке WordPress: **Плагины → Добавить новый → Загрузить плагин**, выберите архив и нажмите «Установить».
1. Активируйте плагин в меню **Плагины → Установленные**.
1. Перейдите к настройке: **WooCommerce → Настройки → Платежи**, включите способ оплаты.

## Настройка Hutkigrosh API v3

### Шаг 1. Получите API-токен

В бизнес-аккаунте ХуткiГрош откройте **Настройки → Интеграция ПУ** (раздел доступен ролям «Владелец ПУ» и «Администратор ПУ»). Используйте токен с доступом к информации о ПУ и созданию/редактированию счетов.

### Шаг 2. Подключите магазин

1. В настройках способа оплаты вставьте токен в поле **API Токен**.
1. Нажмите кнопку **«Актуализировать»** — модуль загрузит из ХуткiГрош списки: **Розничная торговая точка**, **Услуга**, **Кассовое место**.
1. Выберите значения в списках и нажмите «Сохранить изменения».

### Шаг 3. Остальные параметры

**Основное:**
* Название магазина — произвольное название Вашего магазина.
* Путь в дереве ЕРИП — путь, по которому клиент будет искать выставленный счёт (например, `Расчет" (ЕРИП) -> Интернет-магазины/сервисы ->`).
* Срок действия счета (дней) — как долго счёт будет доступен в ЕРИП для оплаты.

**Экран успешного заказа:**
* Секция «Инструкция» — пошаговая инструкция по оплате счёта в ЕРИП.
* Секция «QR-код» — оплата счёта по QR-коду через мобильное приложение банка.
* Секция «WebPay» — кнопка оплаты счёта картой (переход на WebPay).
* Текст успешного выставления счета — может содержать HTML; допустимы переменные `@order_id`, `@order_number`, `@order_total`, `@order_currency`, `@order_fullname`, `@order_phone`, `@order_address`.
* CSS файл для итогового экрана — путь к собственному CSS-файлу оформления.

**Статусы заказов** (идентификаторы существующих статусов WooCommerce):
* Статус при выставлении счета.
* Статус при успешной оплате счета.
* Статус при отмене оплаты счета.
* Статус при ошибке оплаты счета.

**Уведомления** (отправляются шлюзом ХуткiГрош):
* Email-уведомление — письмо клиенту при успешном выставлении счёта.
* Sms-уведомление — SMS клиенту при успешном выставлении счёта.

**Способы оплаты для клиента:**
* Название/Описание способа оплаты (по умолчанию — «Через систему «Расчет» (ЕРИП)»).
* Название/Описание отдельного способа «Оплата картой» (WebPay).

### Обязательно: адрес обработчика уведомлений

Для автоматического обновления статуса заказа (после оплаты клиентом счёта в ЕРИП) сообщите в службу технической поддержки ХуткiГрош адрес обработчика, указав Ваш домен:

```
https://ваш-домен/?wc-api=gateway_hutkigrosh
```

### Тестовый режим (Sandbox)

1. Получите API-токен тестовой системы (при регистрации в ХуткiГрош).
1. Включите в настройках модуля режим **Sandbox** и введите токен тестовой системы.
1. Счета будут выставляться в тестовую систему `api-test-sandbox.hgrosh.by`.
1. Для эмуляции оплаты счёта используйте личный кабинет тестовой системы.

Документация API v3: https://api-dev.hgrosh.by/eripservice/docs/ru/index.html

## Настройка WooCommerce Hutkigrosh Gateway (предыдущее поколение)

1. Перейдите: **WooCommerce → Настройки → Платежи** → способ оплаты «Через систему «Расчет» (ЕРИП)».
1. Укажите параметры подключения:
   * Логин интернет-магазина — логин в системе ХуткiГрош.
   * Пароль интернет-магазина — пароль в системе ХуткiГрош.
   * Уникальный идентификатор услуги ЕРИП — ID услуги в ЕРИП.
   * Код услуги — код услуги в дереве ЕРИП (используется при генерации QR-кода).
   * Sandbox — тестовый режим: счета выставляются в тестовую систему `trial.hgrosh.by`.
1. Настройте остальные параметры (пути в дереве ЕРИП, срок действия счёта, статусы заказов, секции «Инструкция»/«QR-code»/«WebPay», Email/Sms оповещения, тексты способа оплаты — аналогично одноимённым параметрам API v3, см. выше).
1. Сохраните изменения.

### Обязательно: адрес обработчика уведомлений

Адрес обработчика совпадает с версией API v3 (указывается Ваш домен):

```
https://ваш-домен/?wc-api=gateway_hutkigrosh
```

### Тестовый режим

* Используйте данные для подключения к тестовой системе, полученные при регистрации в ХуткiГрош.
* Включите в настройках модуля режим «Песочницы» (Sandbox).
* Для эмуляции оплаты клиентом выставленного счёта воспользуйтесь личным кабинетом
   * [Тестовый кабинет API v3](https://cabinet.hgrosh.by) (сверху-справа «Профиль пользователе» -> «Тестовый режим»)
   * [Предыдущая версия кабинета](https://trial.hgrosh.by) (меню «Тест оплаты ЕРИП»)

## Одновременная работа и переход на API v3

* Плагины — независимы: модуль API v3 ставится **рядом** со старым, заказы и данные магазина не затрагиваются.
* Адрес обработчика уведомлений у обеих версий общий (`/?wc-api=gateway_hutkigrosh`) — сообщать в поддержку новый адрес при переходе не нужно.
* На время перехода **включайте только один способ оплаты** (либо старый, либо API v3), чтобы исключить двойную обработку уведомлений.
* Рекомендуемый порядок перехода: установите модуль API v3 → настройте по шагам выше → проверьте выставление и оплату счёта в режиме Sandbox → переключите способ оплаты на API v3 → деактивируйте старый плагин.
